## `austin-heart-api-server/`

An Express + TypeScript API server that was originally built to back the
Austin Heart demo — sessions, page CRUD, an admin route, pino logging.

It is **not part of the current site and nothing builds it.** Austin Heart
now ships as a static React build with its CMS frozen for demo purposes, so
there is no server at runtime and no database to keep alive.

Rescued from the `austin-heart` branch on 2026-08-16, just before that branch
was deleted. It existed nowhere else. If a practice ever needs a real,
saving-to-a-database CMS rather than a demo preview, start here rather than
from scratch.
